# Со-Действие — сайт

Статический адаптивный сайт, сборка не нужна.

Страницы: `index.html` (главная), `uslugi.html`, `ceny.html`, `sidelki.html`, `baza-znaniy.html`, `statya.html`, `kontakty.html`, `faq.html`.

Служебные файлы (не удалять): `support.js`, `image-slot.js`, папка `img/`, `logo-mark.png`, `logo-mark-light.png`.

## Публикация на GitHub Pages
1. Загрузите содержимое этой папки в корень репозитория.
2. Settings → Pages → Source: Deploy from a branch → `main` / `(root)`.

Локально открывать через веб-сервер (`npx serve`), а не двойным кликом по файлу.
